# Dialog Blog Studio 🎙️

上传资料 → AI 生成男女对话播客 → 卡拉OK字幕播放 → 导出 4K/1080P 视频 + SRT 字幕。

纯前端单文件应用，**无需安装、无需后端**，浏览器直接打开即用。

## ✨ 功能

- **📄 资料上传**：支持 `.txt` / `.md` / `.docx`
- **🤖 两种对话生成方式**
  - 轻松模式：复制提示词 → 粘贴到 DeepSeek / 豆包 / 智谱清言 / Kimi / Grok 等任意 AI 官网 → 回来导入（免 API Key）
  - 全自动模式：填 API Key 直连（智谱 GLM / DeepSeek / Kimi / 自定义 OpenAI 兼容接口）
- **✂️ 长播客支持**：时长可选 20~120 分钟（含自定义），可选分段续写模式，突破单次输出上限
- **🌍 多语言**：中文普通话 / 粤语 / 中英混合 / English / 日本語 / Español / 한국어 / Français / Deutsch / Русский
- **✏️ 对话编辑器**：逐条修改台词、切换角色A/B、排序增删，可导出 SRT 字幕
- **🎬 播放器**
  - 逐字卡拉OK字幕 + 动感音波动画
  - 社交媒体画幅：16:9 / 9:16 / 1:1 / 4:5
  - 字幕拖拽定位 + 左右边缘调宽 + 数值滑杆精确微调
  - 自定义背景图 / 渐变 / 字体（27种）/ 字号 / 角色颜色与性别 / 角色名字
  - 角色可任意组合：一男一女、双女声、单人自问自答
- **🔊 语音引擎（4选1）**
  - 浏览器本机（免费）
  - ✨ Edge 微软真人声（永久免费，晓晓/云希等音色）
  - 硅基流动 CosyVoice（注册送额度，真人感）
  - OpenAI 兼容 TTS API（通用）
  - 音色下拉自选 + 试听
- **🎥 视频导出**
  - Canvas 离屏渲染，兼容性好
  - 清晰度：720P / 1080P（默认）/ 2K / 4K，实时文件大小预览
  - H.264 + AAC 编码，**iPhone / YouTube 直接可用**
  - 导出过程可暂停 / 取消 / 进度条
- **📄 SRT 字幕导出**：时间轴与视频完全同步，可直接导入剪映等配音软件

## 🚀 使用

1. 下载 `index.html`，双击用 **Chrome / Edge** 打开（Mac 亦可用 Chrome）
2. ① 上传资料 → 生成/导入对话
3. ② 编辑对话
4. ③ 播放 & 样式：调背景/字幕/音色 → 导出视频 + SRT

> 所有数据（对话、设置、API Key）仅存于本机浏览器 localStorage，不上传任何服务器。
