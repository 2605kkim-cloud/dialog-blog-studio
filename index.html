🔊 语音音色（TTS）

TTS 引擎
使用微软 Edge 的在线语音（晓晓/云希等真人感音色）。播放时会自动列出系统可用音色；若 Windows 没装对应语音包，去 设置→时间和语言→语音 添加。完全免费无限量。
📢 下面这两个下拉是本机/Edge 引擎的音色选择（系统语音包），仅这两个引擎有效：
♂ 男声音色
♀ 女声音色
默认「自动」按语言+性别智能挑选；也可手动指定任意系统音色。列表随系统语音包变化，Mac 上会显示苹果自带的音色。
📢 API 模式的音色是在这里填音色名（由服务商定义，如 nova/onyx），上面那两个下拉对 API 无效：
♂ API 男声音色名
♀ API 女声音色名
请求格式：POST {model, input, voice, response_format:"mp3"}，兼容 OpenAI TTS 格式的服务
